## Run Locally

Clone the project

```bash
  git clone https://github.com/FencingLefty3/fencinglefty3.github.io
```

Go to the project directory

```bash
  cd fencinglefty3.github.io
```

Start the LocalHost

```bash
  python -m http.server
```
